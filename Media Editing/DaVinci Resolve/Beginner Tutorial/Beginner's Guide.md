- DVR is like several programs packed in one
- These programs are presented as **Pages**
	- *Media Page*
	- *Cut Page*
	- *Edit Page* : Putting the clips together as a story on a storyline
	- *Color Page*
	- *Fusion Page* : Effects and Graphics
	- *Fairlight Page* :  Audio mixing

> **Media Page**

- `Media Storage Panel` : Navigate the system where the media are stored
- `Media Pool` : Anything in the *Media Pool* Lives in the project
	- Able to Create Folders in the *Media Pool*, This folder is called **Bin**
- Drag Folders and Filed in the Media Pool Lists section to Add the corresponding folders otherwise it will dump all the media content in one *Master Bin*
- **Sync Audio** : 
	- Select the Video and Audio files
	- `RMB > Audio Sync > Auto Sync Audio > Sync with Waveform` 
		- Replaces the Audio of the video clip with the Audio File
