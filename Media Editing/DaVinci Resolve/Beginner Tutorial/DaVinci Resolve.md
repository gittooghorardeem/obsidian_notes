>> **Keyboard Shorts**

- `Ctrl + F` : Full Screen media playback
- `I` : *Set IN*  while scrubbing
- `O` : *Set OUT* while scrubbing
- `J` : *Backwards*
- `K` : *Stop*
- `L` : *Forward*
- `B` : Edit : Blade tool
- `A` : Edit : Selection tool
- `Backspace` : Edit : Delete Selected
- `D` : Edit Timeline : Disable Clip
