 **Keyboard and Mouse**

> **Keyboard**

- `F` : Brings focus back on the Selected object
- `Q` : Select Object
- `W` : Movie obj directionally 
- `E` : Rotate Obj
- `R` : Scale Obj
- `green` : *Y axis* 
- `red` : *X axis*
- `blue` : *Z axis*
- `ALT + D + Select and Drag` : Duplicates selected object
- `CTRL + Space` : Content Drawer
- `G` : Goes in to game mode instead of Hitting Play
- 

> **Mouse**

- `RMB + W/A/S/D` : Move around freely in the viewport

> **Navigation**

- `Tools > Visual Studio 2022 > Open Visual Studio 2022`
- `Editor preferences > General > search Code Editor` : setting up default Code editor
- `Windows > Load Layout > UE4 Layout`
- UI Navigation 
	- File
	- Edit
	- Window
		- Add multiple viewport
	- Tools
		- Create a new C++ class
	- Build 
		- Building lighting
- `Performance and Scalability tools` : Engine Scalability Settings 
  ![[engine_scalability_settings.png]]

> **Command**

- `~` : to open the command window
- `stat fps` : displays the FPS in the view port
- `t.max fps ###` : Set FPS limit
