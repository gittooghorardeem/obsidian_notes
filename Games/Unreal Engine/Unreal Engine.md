**Keyboard and Mouse**

> **Keyboard**

- `F` : Brings focus back on the Selected object
- `Q` : Select Object
- `W` : Movie obj directionally 
- `E` : Rotate Obj
- `R` : Scale Obj
- `green` : *Y axis* 
- `red` : *X axis*
- `blue` : *Z axis*
- `ALT + D + Select and Drag` : Duplicates selected object
- 

> **Mouse**

- `RMB + W/A/S/D` : Move around freely in the viewport
